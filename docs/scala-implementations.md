# Scala Pilon Feature Implementations

## 1. Scaffold.findCircles() — Circular Contig Detection

This method identifies circular contigs (e.g., plasmids) from unpaired read alignments. It first collects "cantalevered" alignments—reads whose unclipped ends extend beyond the contig boundary with at least `EndMinOverlap` (500 bp) of aligned bases—indicating the read spans the circular join point. These end alignments are grouped by read name into pairs (`EndAlignmentPair`), and pairs linking the same two contig ends (e.g., "contigL" and "contigR") with at least `EndMinLinks` (5) supporting pairs are clustered. For each candidate circle, the implied lengths from all supporting pairs are sorted and a robust estimate is computed via `estimateLength()`, which finds the tightest cluster of at least 5 consecutive estimates within 20% of each other and takes the median; the resulting contig name → estimated length map is returned for downstream circle-closing assembly.

## 2. GapFiller.recruitLocalReads() and fixBreak() — Local Break Repair

`recruitLocalReads()` gathers fragment-pair ("frags") and unpaired reads from BAM files overlapping the break region, providing the raw read data for reassembly. `fixBreak()` orchestrates local de Bruijn assembly around a contiguity break: it recruits reads, invokes the `Assembler` to build an assembly graph from both flanking sequences, and attempts to find a bridge path via `multiBridge`. The resulting forward and reverse paths are joined through `properOverlap()`, which finds the minimum overlap >= K that aligns the paths end-to-end. If a unique clean join is found, it is trimmed to remove matches to the original reference and returned as a patch. If no clean join exists, the method falls back to building consensus sequences from each side; if at least one side extends non-trivially beyond the original break and does not merely recapitulate the reference, it inserts a new gap between the two consensus extensions rather than leaving the misassembly uncorrected.

## 3. Tracks.makeTrack() and makeBedTrack() — Visualization Output

`makeTrack()` writes a UCSC WIG file by iterating over every base position in all genome regions and applying a caller-supplied lambda function `(GenomeRegion, Int) => Int` to compute a per-base scalar value, outputting it in `fixedStep chrom=... start=... step=1` format with configurable track display options (e.g., heatmap ranges for GC track, view limits for SD tracks). `makeBedTrack()` writes a BED-format file that summarizes all issues Pilon detected in a region: unconfirmed bases ("?", teal), changes ("X", red), low coverage ("LowCov", purple), collapsed repeats/copy number variants ("Copy#", olive), duplications ("Duplication", orange), gaps ("Gap", black), possible breaks ("Break", magenta), and reassembly outcomes (green). Each region type is assigned a distinct RGB color, making the BED file suitable for visual inspection in IGV.

## 4. GenomeFile.assembleNovel() — Novel Sequence Discovery

This method assembles sequence present in the reads but absent from the reference genome. It first builds a "genome graph" by adding all reference contig sequences to a background `Assembler` at `minDepth=1` (capturing known k-mers without requiring depth). It then creates a separate `Assembler`, adds all unmapped reads (excluding jumps) from the BAM files, and calls `assembler.novel(genomeGraph)`, which finds paths through the read assembly graph that are not present in the genome graph—representing novel insertion sequences. The resulting contigs are collected, their lengths are reported, and they are appended to the output FASTA with headers like `pilon_novel_001`.

## 5. GenomeRegion — copyNumber, gc, computeGc, deltaCoverage, dipCoverage

- **copyNumber**: A per-base `Short` array computed during `postProcess`. It takes the `fragCoverage` array (coverage from fragment-pair reads only), smooths it with a 200-base sliding window, divides each smoothed value by the mean fragment coverage, and rounds to the nearest integer. Values > 1 indicate possible collapsed repeats or duplications.
- **gc** and **computeGc()**: `gc` is a per-base `Byte` array. `computeGc(window=100)` slides a circular buffer over the entire contig to compute local GC content: for each position, it maintains a running count of G/C bases in a `window`-wide buffer, updating incrementally as it advances. When the center of the window falls within the region, the count (0–100) is stored in `gc(index)`. The result is used for the GC content Wig track with a heatmap color scheme.
- **deltaCoverage(i, radius)**: Computes the absolute difference in fragment coverage between positions `i - radius` and `i + radius` (default radius=100). It measures local coverage asymmetry; large values indicate abrupt coverage changes characteristic of structural variation boundaries, and it is used in `deltaFraction` (normalized by mean coverage) to detect collapsed repeats and possible breaks.
- **dipCoverage(i, radius)**: Computes `(left - center) + (right - center)` = `left + right - 2*center`, measuring how much coverage drops at position `i` relative to its flanks. This identifies local coverage valleys (dips) that may indicate misassemblies, heterozygous deletions, or other structural variants. When `dipFraction` (dipCoverage / mean coverage) >= 1.5, the locus is flagged as a possible continuity break.
